# 开放式业务工作区

2026-11-10，依据本轮页面布局调整。替代旧实现注释中“所有业务页面固定三栏”和“模块导航即战况板”的布局决定；不改变业务归属、权益和权限。

## 信息层级

- Header：产品、组织/空间、搜索和全局工具。移除全局左栏展开/收起按钮。
- Launcher：跨业务模块切换。保留五组业务分类，模块名称下显示既有服务提供的数量/金额摘要；锁定模块只展示档位，不显示业务数字，无权限模块不出现。
- 页面：当前模块的实际工作内容。筛选、视图切换、业务动作与页面标题同行或紧邻列表，不把其他模块名称重复放在左栏。
- 内部导航：仅在存在同一模块内的不同功能或对象视图时出现，例如客户详情的分析标签、配置管理的功能菜单。简单清单不新增导航。

## 按页面类型安排空间

| 页面 | 布局 |
|------|------|
| 客户、商机、产品等清单及普通业务页 | 主内容 + 可开关的右侧助手，无左侧模块卡片列 |
| 客户、商机详情 | 对象档案 + 主内容 + 按需开启的助手；档案是信息区，独立于配置菜单的折叠偏好 |
| 新建、编辑表单 | 保留表单自身内容宽度和分组，不增加业务模块导航 |
| 配置管理 | 保留 DS 原生功能菜单，其收起按钮留在菜单内部；无业务助手 |
| 跨域聚合页 | Launcher 进入，使用页面原有内容结构，不新增重复左栏 |

## 开放式与卡片的取舍

开放式是默认组织方式：页标题、连续指标、列表和同一任务的分析分节直接落在内容平面上，以 DS 字阶、间距和分隔区分层级。页标题保留 DS 浅色虚线及其 `pb-lg` 内留白，内容区再由 `ViewLayout gap-xl` 留出线下距离。使用 `ViewHeader`、默认 `Section`，不通过全局 CSS 抹掉 DS 的边框、圆角或阴影。

保留卡片的场景：可独立操作的对象、看板条目、待裁决提案、明确的危险动作、浮层与助手面板。它们有单独的交互或状态边界，不能只为了“去卡片”而失去边界。

连续指标使用文字和数字分组，宽屏一行，小屏允许两列，不再给每个数字单独套卡片。列表本身已有行、列和筛选边界，无需额外的页面级外框。

## 本轮落地与验证

共享壳层移除重复模块左栏，Launcher 复用 `board.modules` 的已门控数据，删除不再使用的 `NavBoard`。共享 `ModuleHeadline` 移除 `Card` 外壳，覆盖所有使用该组件的模块。商机管道指标和承诺达成页改为 DS 开放式分节；保留看板条目、对象档案和助手操作边界。

不增加统计读取，不改变统计口径；本轮未将全站所有卡片机械替换。后续单个页面调整继续按上面的任务边界判断。

本地使用内存演示数据检查客户、商机、承诺达成、产品、对象详情及配置管理；覆盖 Launcher、原左栏折叠 cookie、助手开关，以及窄屏列表。发布前仍走 PR 和 CI。

## 第二轮：独立分区与操作尺寸

三栏不再共用带 padding/gap 的外层内容框。Header 之外，配置导航使用 DS `sidebar` 插槽，助手使用 `dock` 插槽；对象档案与业务内容在主区内直接并列。每区独立控制宽度、内边距、分隔边和滚动；关闭助手直接释放主区宽度。空导航不保留占位。布局容器仍负责 Flex 排列，不代表增加一层卡片。

- 页面标题只出现一次。客户、营销活动去掉重复内容标题；销售规划中的目标表称“销售目标”。商机页不再重复打印“商机管道”，直接展示指标与表格。产品的在售/退役等真实分组标题继续保留。
- 页级操作和整行筛选使用 32px（DS `xl`）。输入框、筛选、重置、视图按钮和同排动作同高。
- 密集局部操作、表格内动作使用 24px（DS `md`），原显式 16/20/28px 的业务按钮归并到这一档。
- 标签与状态徽章不是操作按钮，保留 DS 原有尺寸；多行文本、树节点、菜单项也不强制压成固定行高。
- 标签切换的外组为 32px，沿用 DS 4px 内边距，内部标签为 24px。保留各组件的状态、字体与配色。

`business-controls.tsx` 只绑定上述业务尺寸到 DS `FilterBar`、`TabsList`、`ViewHeader`，不重做交互。DS 组合控件没有统一尺寸参数，临时尺寸绑定与退出条件记录在 TD-038。
