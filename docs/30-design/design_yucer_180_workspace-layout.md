# 开放式业务工作区

2026-11-10，依据本轮页面布局调整。替代旧实现注释中“所有业务页面固定三栏”和“模块导航即战况板”的布局决定；不改变业务归属、权益和权限。

## 信息层级

- Header：产品、组织/空间、搜索和全局工具。移除全局左栏展开/收起按钮。
- Launcher：跨业务模块切换。保留五组业务分类，模块名称下显示既有服务提供的数量/金额摘要；锁定模块只展示档位，不显示业务数字，无权限模块不出现。
- 页面：当前模块的实际工作内容。筛选、视图切换、业务动作与页面标题同行或紧邻列表，不把其他模块名称重复放在左栏。
- 内部导航：仅在存在同一模块内的不同功能或对象视图时出现，例如客户详情的分析标签、配置管理的功能菜单。简单清单不新增导航。

## 按页面类型安排空间

| 页面 | 布局 |
|------|------|
| 客户、商机、产品等清单及普通业务页 | 主内容 + 可开关的右侧助手，无左侧模块卡片列 |
| 客户、商机详情 | 对象档案 + 主内容 + 按需开启的助手；档案是信息区，独立于配置菜单的折叠偏好 |
| 新建、编辑表单 | 保留表单自身内容宽度和分组，不增加业务模块导航 |
| 配置管理 | 保留 DS 原生功能菜单，其收起按钮留在菜单内部；无业务助手 |
| 跨域聚合页 | Launcher 进入，使用页面原有内容结构，不新增重复左栏 |

## 开放式与卡片的取舍

开放式是默认组织方式：页标题、连续指标、列表和同一任务的分析分节直接落在内容平面上，以 DS 字阶、间距和分隔区分层级。页标题保留 DS 浅色虚线及其 `pb-lg` 内留白，内容区再由 `ViewLayout gap-xl` 留出线下距离。使用 `ViewHeader`、默认 `Section`，不通过全局 CSS 抹掉 DS 的边框、圆角或阴影。

保留卡片的场景：可独立操作的对象、看板条目、待裁决提案、明确的危险动作、浮层与助手面板。它们有单独的交互或状态边界，不能只为了“去卡片”而失去边界。

连续指标使用文字和数字分组，宽屏一行，小屏允许两列，不再给每个数字单独套卡片。列表本身已有行、列和筛选边界，无需额外的页面级外框。

## 本轮落地与验证

共享壳层移除重复模块左栏，Launcher 复用 `board.modules` 的已门控数据，删除不再使用的 `NavBoard`。共享 `ModuleHeadline` 移除 `Card` 外壳，覆盖所有使用该组件的模块。商机管道指标和承诺达成页改为 DS 开放式分节；保留看板条目、对象档案和助手操作边界。

不增加统计读取，不改变统计口径；本轮未将全站所有卡片机械替换。后续单个页面调整继续按上面的任务边界判断。

本地使用内存演示数据检查客户、商机、承诺达成、产品、对象详情及配置管理；覆盖 Launcher、原左栏折叠 cookie、助手开关，以及窄屏列表。发布前仍走 PR 和 CI。

## 第二轮：独立分区与操作尺寸

三栏不再共用带 padding/gap 的外层内容框。Header 之外，配置导航使用 DS `sidebar` 插槽，助手使用 `dock` 插槽；对象档案与业务内容在主区内直接并列。每区独立控制宽度、内边距、分隔边和滚动；关闭助手直接释放主区宽度。空导航不保留占位。布局容器仍负责 Flex 排列，不代表增加一层卡片。

- 页面标题只出现一次。客户、营销活动去掉重复内容标题；销售规划中的目标表称“销售目标”。商机页不再重复打印“商机管道”，直接展示指标与表格。产品的在售/退役等真实分组标题继续保留。
- 页级操作和整行筛选使用 32px（DS `xl`）。输入框、筛选、重置、视图按钮和同排动作同高。
- 密集局部操作、表格内动作使用 24px（DS `md`），原显式 16/20/28px 的业务按钮归并到这一档。
- 标签与状态徽章不是操作按钮，保留 DS 原有尺寸；多行文本、树节点、菜单项也不强制压成固定行高。
- 标签切换的外组为 32px，沿用 DS 4px 内边距，内部标签为 24px。保留各组件的状态、字体与配色。

`business-controls.tsx` 只绑定上述业务尺寸到 DS `FilterBar`、`TabsList`、`ViewHeader`，不重做交互。DS 组合控件没有统一尺寸参数，临时尺寸绑定与退出条件记录在 TD-038。

## 第三轮：内容外缘与分栏留白

内容区左右分别按实际相邻区域控制留白，不再固定使用两侧 24px。默认密度下，宽度至少 1280px 的桌面，直接面对浏览器边缘的一侧使用 DS `space-3xl`（48px），与档案、配置导航或助手相邻的一侧使用 `space-lg`（24px）。两侧都无侧栏时为 48/48；仅左栏为 24/48；仅右栏为 48/24；左右栏同时存在为 24/24。

小于 1280px 时，外缘使用 DS 原生 `space-page-inset` 流体间距，随视口缩减，默认密度最低 24px。业务侧栏（对象档案和助手）自身水平内边距统一为 `space-lg`。沿用 DS 密度轴，不另设像素色板或间距刻度；不更改 Header、页面顶部位置、三栏宽度和独立滚动。

规则在共享壳层生效，详情页通过实际渲染的档案判断左侧是否有相邻区域，加载失败未出现档案时也使用外缘留白。配置管理沿用 DS 页面容器的最大宽度与垂直间距，仅接入同一套水平留白。没有添加外层公共 padding，也不预留隐藏侧栏的空间。


## 产品与方案的状态分组

产品目录、解决方案保留一个模块主标题，列表按生命周期各分两组。产品为“当前产品 / 退役产品”：当前产品包括在售、在研和工作区自定义的非退役状态，不将其误称为全部在售。方案为“在用方案 / 停用方案”。组标题使用 DS `list-checks` / `archive` 图标，分别表达当前清单与归档，不重复模块主标题图标。

搜索、类型筛选、新建和视图切换放在两组上方，统计数量对应两组合计，避免工具行属于第一组、实际却筛选两组的歧义。退役与停用组固定保留；没有记录时显示对应空状态，筛选无匹配时显示统一无匹配状态。保留现有状态变更、权限和行操作规则，不改变产品或方案的业务状态。

## 产品与当前定价合并

产品目录统一展示产品信息和当前价格，Launcher 移除独立的“产品定价”入口。`/pricebook` 保留查询参数并跳转到 `/catalog`；价格评估及已选产品通过目录的助手栏继续使用。产品编辑仍检查 `catalog.write`，调价仍检查 `catalog.price`，历史价格删除沿用服务端保护，不扩大权限。

主表在计价单位后设置一个价格列，标准价为首行主信息，审批价、保底价以辅助小字号并排组成第二行；零值正常显示，缺少的项目不展示，不以零代替。无当前价目的产品保留在清单中，显示未定价。当前价格按默认币种与服务器时间读取；只有历史记录或待生效记录的产品不计为当前已定价。

每个产品的操作菜单提供设定/重新定价及价格记录。记录通过 DS Drawer 展示，明确区分生效中、待生效、历史价格，不再用“历史价目”概括未来生效的版本。调价使用 DS DialogForm，继续追加价格版本，不修改旧版本。退役产品可查记录，不提供新的调价入口。

保存规则保持三项完整，且 `0 <= 保底价 <= 审批价 <= 标准价`。输入标准价后，审批价按标准价减少 30%、保底价减少 50%，四舍五入取整数；不足一单位的输入仍保证建议值不超过标准价。每个派生字段单独记录手动修改，修改后不随标准价变化被覆盖；恢复默认折扣后重新联动。重新定价初始值保持原价，只有更改标准价或点击恢复默认才重新建议。默认折扣是可修改的填写建议，不改变报价审批或数据库规则。

合并表格沿用 DS 自动列宽并设置 DS `container-4xl` 最小宽度，窄内容区由表格自身横向滚动，避免价格标签或金额挤入相邻列。价格记录保留各币种版本，主表仍显示工作区默认币种的当前价。

## 解决方案价格展示与组合填写

解决方案沿用产品目录的两行三档价格展示，名称后的一个价格列呈现标准价主信息与审批价、保底价辅助信息，并标明默认币种；列表与卡片使用同一展示组件。合计为标配行的当前产品单价乘数量，可选项不计入。使用产品实际审批价与保底价，不从方案标准价重新计算七折、五折，以保留产品手工定价结果。

新建与修改方案时，各产品行展示当前三档单价，组合下方实时预览合计；产品、数量及标配/可选变化同步更新。缺价按每档独立统计并标记，全部缺失显示未定价，零价正常保留。只读取默认币种当前生效的版本，不混入历史、未来或其他币种。价格维护入口另开产品目录，保留未保存的方案草稿；调价仍使用产品的默认折扣与手工修正规则。

方案继续作为产品组合模板，不新增独立方案价格或写入价格的权限；保存方案只提交原有组合字段。方案编辑行主要输入及页级操作使用 32px，紧凑移除及维护入口使用 24px。表格使用 DS 自动列宽与自身横向滚动，避免内容区变窄时价格相互挤压。


## 价格的两行层级与完整提示

所有产品价格展示（目录、卡片、价格记录、方案合计与组合编辑预览）共用两行层级：第一行标准价为 DS `text-body`（14px）与中等字重，第二行审批价、保底价并排，使用 `text-body-small`（12px）与辅助语义色。分别使用 DS `coins`、`seal-check`、`shield-check` 图标代替常显文字标签；数字不缩略，不将零价格省略。

价格列标题与内容统一居中，两行价格块内部同样居中。价格整体使用 DS Tooltip，悬停或键盘聚焦可查看完整的三档名称、金额、币种及各档缺价数量；辅助技术同时读取完整文本。方案存在缺价时保留警告图标，详细数量收进提示，避免缺价徽标挤压价格行。产品列表列顺序为名称、产品类型、计价单位、价格、状态；解决方案的计价口径为整份标配组合，价格列同样放在计价单位之后。


## 产品与方案清单列顺序统一

产品目录与解决方案主表统一为名称、产品类型、计价单位、价格、状态、操作；选择与序号列沿用共享表格规范。方案类型使用组合覆盖的真实产品类型；方案没有独立存储的计价单位，展示口径为“方案”，Tooltip 说明每份完整标配组合，不含可选项且不改变各产品的计价单位。价格保持两行居中与默认币种，缺价提示不变。

方案适用场景、简介及组合明细移入 DS 只读 Drawer，不再以长文本独占主表列。点击列表或卡片名称、行菜单的方案详情均可打开，读者无需维护权限。场景与简介保留搜索匹配。Drawer 展示完整文字、标配三档合计，以及各产品编码、数量、标配/可选和定制说明；组合明细使用 DS DetailList，保留阅读空间。停用方案也可查看，不改变启用、停用、排序、删除或保存规则。
