# ADR-043 默认销售角色只做初始化

- 状态：accepted
- 日期：2026-11-18

## 决定

平台已授权进入聿策的普通成员默认成为现有销售代表（`sales_rep`）。默认分配政策与
角色所含权限是两个层面；不新增角色、不改变销售代表权限与数据范围。

使用 `local_authz.member.role_setup_complete` 持久区分未配置成员与明确撤销授权的成员。
迁移将已持有角色、已停用及有成功角色/状态管理审计的成员标为已配置。历史活跃且
从未配置角色的成员在下次有产品权益进入时补齐，无需管理员逐个开门。

默认分配在成员行锁内复核活跃状态、初始化标记和已有角色，角色链接、标记与审计同事务
提交。显式授予、撤销、停用/启用写入同一标记并使用相同行锁，管理员决定优先。
租户移除了默认角色时不重建；仍由管理员分配适合的角色。

所有者保持现有无角色恢复策略，但停用优先。产品权益门和业务权限门继续独立生效；
权限来自工作区角色表，不增加平台治理角色到产品权限的映射。

## 验证

覆盖新成员、历史未配置成员、订阅前访问及缓存转换、租户定制角色、显式降级/撤销、
停用与重新启用、默认角色缺失、并发初始化与管理员变更、审计事务和服务角色列权限。
数据库按旧版升级、重复执行、全新建库三个路径演练。
