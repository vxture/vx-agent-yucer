# ADR-042 战略制定结果与助手草稿

- 状态：采用，本地验证完成，尚未发布
- 决策依据：owner 接受战略结果基础区/高级设置及版本方案，补充基本信息四字标题、市场附带客户规模、同步助手。

## 决策

在现有战略聚合上扩展结构化结果，不建立第二份战略对象或重复 KPI。保留名称、执行周期、
创建人、编号和草稿/发布/修订流程；已发布版本只读。新编辑器保存完整结果，历史空结果保持兼容。
经营目标中的三个原指标投影为既有 expectations，沿用目标 UUID 与销售规划承接。
自定目标只有明确数据源时才获得实际进度，不能推测或混合求和。

价值主张与实现路径使用工作区字典配置，引用 UUID；历史发布冻结名称。
市场/产品新旧按本战略关联标注，未知保留未知；一致性提醒不构成硬门禁。
草稿可不完整，发布检查必填。新/改达成日期检查当天边界，原有历史日期保留。

助手复用 Atlas/Runos 共享回合、会话与重试链路，仅回填当前表单。模型响应必须有可解析字段，
不能用声称完成代替回填；服务端验证选项、人员与关联，人工复核后使用相同保存与发布能力。
创建人由会话记录，不由模型指定。框架助手标题不改，任务名称作为内容提示。

## 数据与兼容

incr/0125 增加 result 与 strategy_option，服务角色列授权与 Prisma 同步。
数据库冻结发布内容，复制修订结果，检查工作区字典及目标投影；既有发布快照不回填、不改写。
战略依赖、补充价值主张、渠道/商业模式仅保留模型扩展位置，本期无界面。
