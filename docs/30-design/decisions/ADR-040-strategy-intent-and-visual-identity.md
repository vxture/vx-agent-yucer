# ADR-040 战略类型与视觉表达

- 状态：accepted
- 日期：2026-11-17
- 来源：负责人要求企业战略独占一行，突出宏观主张，并提供可配置类型与差异背景。

## 决定

战略仍可同期并行，不因视觉改版合并战略或改变目标、市场、活动的所有权。
每份战略可选择一个主类型。预置市场深耕、市场开拓、产品创新、生态协同、多元布局，
分别表达既有市场深化、新市场进入、新供给增长、伙伴协作和组合探索；不是行业标签、
成熟度评分或审批状态。管理员可修改名称、说明、排序、启停状态以及五种受控背景主题，
也可增加自定义类型。类型不影响统计、商业档位或权限规则。

类型配置由 D1 负责，按工作区隔离。配置编码创建后固定，引用不能跨工作区；配置只停用、
不删除。战略草稿允许改变类型引用，正式版本禁止改变。发布快照冻结当时的类型名称、
说明与背景主题；配置后续变化不改写旧版本。修订继承类型引用，停用的既有选择可保留，
但新建或改选只能选择启用类型。旧战略留空，不从名称猜测类型。

`strategy_type_code` 是草稿中的分类引用，不是战略自身的业务编号。列锁允许该引用变更，
数据库触发器限定草稿；配置行自身的 `code`、战略 `plan_no` 仍保持不可变。
因此列锁回归针对这一列增加有范围的例外，并以真实服务角色的数据库测试验证发布后冻结。

## 展示与实现

战略总览的卡片始终一行一份。名称与战略主张优先，目标市场和主推产品方案作为第二信息区，
负责人、周期、版本和统计作为支撑。保留原列表对比模式及原生命周期操作。

使用 DS Card、Icon、Button、Tag、配置词表和表单控件；颜色和间距来自 DS。
背景为本仓代码原生 SVG 轴测线稿，通过遮罩使用语义颜色，兼容深色主题；
没有外部图片请求或上传图片入口。背景仅装饰，不承载唯一业务信息。
设置入口为 `/admin/strategy`，同时出现在配置管理与战略总览操作区。

结构由增量 0115 提供，列锁和 Prisma 同步。配置面按既有管理面规则不绑定商业功能键，
复用 strategy.read / strategy.write 权限，业务页面仍受战略商业权益门约束；
不增加商业能力键或权限码；上线需先执行数据库增量，再部署应用。
