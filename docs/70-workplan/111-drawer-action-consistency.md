# UI-DA 抽屉操作按钮一致化

Issue：[#727](https://github.com/vxture/vx-agent-yucer/issues/727)。
与 #725 一起由 [PR #726](https://github.com/vxture/vx-agent-yucer/pull/726) 审查。用户已确认发布，统一准备 v0.1.125，生产尚未变更。

## 原因与范围

抽屉底部动作常用 DS 默认档或 md，现有全平台适配将其高度统一到 32px，
但字号仍为 12px。只有显式 xl/default 等少量主动作保留 14px，导致主次按钮字体不一。
只改 size 无法修复次要按钮，因为产品层字号适配仍覆盖 DS 档位。

源码逐处梳理 52 个 DS Drawer 调用，其中 28 处使用真正的 footer，
其余包括阅读抽屉、内容区内的表单动作、工作流及历史行操作。
通过 JSX 语法树限定真实 Drawer footer，避免把 MetricListCard 的 footer 误认为抽屉底栏。

## 统一行为

- 标记并统一 75 处直接动作按钮：DS xl / 32px 高、14px 字号、最小宽度 48px，
  主次按钮同高同字阶，主次颜色、权限、禁用与保存行为保持原定义。
- 决策角色抽屉的保存按钮经 SaveRow 共享组件渲染，增加显式 drawerAction 选项；
  表格 SaveCell 等调用不启用该选项，继续保留原尺寸。
- 覆盖战略关联、细分市场产品方案、客户基础资料、合同、联系人、重点客户、
  商机、销售规划及组织/成员/角色抽屉；同时覆盖内容区末尾的取消、应用、发布、恢复等动作。
- 历史表格行按钮、指标预置选择、证据撤销、标题收起、浮层关闭等仍按原紧凑或常规规格。
- 继续复用 TD-038 的产品控件适配及 DS token，不复制或修改 DS，不新增依赖或数据库变更。

## 验证

- 类型检查、83 页页面/控件规范、DS 字体与文档编号检查。
- 承接抽屉在 1440 / 720 / 390px 下确认主次按钮均为 32px / 14px，
  取消 78px、确定承接 106px，同行对齐、间距 10px，无横向溢出；底部安全区 80px。
- 其余代表性抽屉与最新 CI 结果回填 Issue #727。

本批仅样式与显式控件标记，不触发生产发布。用户已确认本地预览，批量准备 v0.1.125。
