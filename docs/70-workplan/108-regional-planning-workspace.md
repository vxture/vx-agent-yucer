# 区域拆分工作区 RP-01

跟踪 [Issue #720](https://github.com/vxture/vx-agent-yucer/issues/720)。
本批承接公司规划 CP-01、CP-02 与公司战略承接修正，与本轮销售规划统一验收、统一发布。
不按单条反馈创建应用版本，生产应用当前为 v0.1.123。

## 布局与操作

- 公司发布版作为只读基准，明确来源版本；区域草稿不修改公司目标与周期。
- 区域总览保留 card/list、搜索、参与状态筛选与排序，按公司指标查看三档分配并直接编辑。
  展示公司目标、已分配、待分配与单区域占比；分配明细帮助分别列出三档余额。
- 单区域继续使用同一目标组件：年度三档、季度四列、框内比例、毛利率与估算金额、
  管道覆盖倍数、新客整数、精简/完整模式，标准 DS 抽屉与页面底部安全区。
  纳入状态和负责人并列，缺项显示待核定，负余额保留超配提示。
- 所有修改进入同一共享区域草稿；保存、规划检查、具名区域发布和不可变版本继续沿用。

## 拆分与助手

- 区域营收季度自动拆分采用公司已发布季度节奏；公司缺少完整有效节奏时沿用可调预置。
  其他指标按本区域营收节奏拆分。金额按分、新客按整数，尾差落在最后开放季度。
- 已有区域分配不自动重新均分，锁定季度保留；缺失的锁定季度不凭空补造数据。
- 首轮新客整数按年度区域容量分配季度余量，避免季度少量客户全部堆到最后一个区域；
  年度区域差不超过 1 家，同时保持公司各季总量及三档关系。
- 区域新增辅助指标参考公司同指标与本区域营收占比；毛利率继承明确公司率，
  不另套独立的默认行业新客估算。明确已有数量不覆盖。
- 单区域战略自动分解只操作本区域开放季度，保留其他区域和关闭季度；
  没有分配的战略预期在编辑中可见，按剩余核定额度与财务容量分配，不反向修改公司核定值。
- 继续通过 Atlas/Runos 调用模型，提示包含公司基准、其他区域目标与同季容量；
  不新增模型接入。助手只回填草稿，不宣称已经保存或发布。
