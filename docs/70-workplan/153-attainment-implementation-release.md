## R1-02：统一指标与诊断读模型

- [x] 页面和小聿复用受控BFF／领域服务；服务端执行租户、工作区、成员、范围及权益校验，
  撤权后重新校验或失效，智能体不直连数据库。
- [x] 已发布公司／区域／团队／个人目标按所选版本和期间读取实际保底／目标／挑战，
  不按人数分配、固定60%／120%或借年度档位生成季度目标。
- [x] 成交、客户新老构成／周期拉新、储备与毛利使用各自口径；不混币种，不把存量相加当期间增量，
  不把当前负责人当作历史业绩归属。公司净缺口与分区缺口之和可不同，差额有解释。
- [x] 新老客户按真实首次合作与业务年度判定，包含系统启用前历史；补录日期或“某年度前已合作”
  走客户原服务与权限，支持历史未知待确认。登记、导入、换负责人均不算拉新，季度只改变本季新增。
- [x] 存量客户缺历史时不批量认定新客；历史年度缺快照不借当前存量生成旧年度构成。
  未合作客户保留原生命周期，不伪装成老客户或新合作客户。
- [x] 客户目标接入正式规划与真实验收依据；定性目标没有验收记录则待核验，不以计划节点明确代替完成。
  最小补录能力若需扩展，遵守拥有域及修订／审计规则，不启动完整伙伴管理等无关业务。
- [x] 商机按客户身份分组，每项目独立主责、协作、金额、节点与依据；协作不计本人主责储备，
  问题诊断按结构化业务事实，不将原型中文关键词匹配当生产规则。
- [x] 储备覆盖按缺口及有效业务范围计算，2×／3×／4×为候选参考档位，优先已有业务配置；
  毛利金额主显、率紧靠金额，采用可信财务来源，缺成本时显示未知，不造分子。
- [x] 差额＝实际－目标。默认各期独立，勾选后不足／超额均逐期滚动，未知链停止推算；
  年度原目标、原承诺达成率、历史报送均不因此改写，未载入下期保留待接续状态。

完成效果：关键数字能够回查记录与口径，单条异常不抹掉其他已核实事实。
缺失外部财务来源不以虚假数字解锁，应如实展示且列入发布说明。
