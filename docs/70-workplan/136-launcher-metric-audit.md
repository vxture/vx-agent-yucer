# C02 Launcher 数字全模块审计

发布暂停。数字表达可见业务事实，悬停显示完整口径；确实为零显示 0，读取异常显示破折号和暂不可用提示，权限不足不显示数字。库存数字用于理解业务覆盖，执行数字优先反映待办。

| 域／板块 | 原数字／问题 | 本批口径 | 意义及权限 |
|---|---|---|---|
| 战略规划／战略总览 | 当前战略数 | 保留当前战略数 | 当前版本去重，经战略读取双门控 |
| 细分市场 | 市场条数 | 保留 | 市场覆盖库存，经细分市场门控 |
| 解决方案 | 方案条数 | 保留 | 可选方案库存，经方案门控 |
| 产品目录 | 产品条数 | 保留 | 产品库存，经产品门控 |
| 作战部署／销售规划 | 指标条数，无经营价值 | 已发布营收目标值，提示具体周期、币种 | 按个人／区域／全工作区范围选同一级目标，优先年度，不累加上下级、年度与季度；币种分别列示 |
| 重点客户 | 始终无数字 | 当前年度有效版本重点客户去重数 | 复用重点客户页面投影及数据范围，跳过联系人／覆盖详情；不拿客户等级冒充规划名单 |
| 承诺达成 | 达成率被截到 100% | 保留真实达成率，允许超过 100% | 无有效目标或测量时不伪造百分比 |
| 赢丢复盘 | 待复盘数量 | 保留 | 已结束但缺复盘的商机，经复盘读取门控 |
| 战场侦察／营销活动 | 活动数 | 保留活动库存 | 完整活动组合，经活动门控 |
| 商机智探 | 含终态全部信号 | new／scored 待判断数量 | 与 C01 待判断队列一致，复用成员可见信号服务 |
| 线索管理 | 缺数字 | 跟进中线索数；提示待分派数 | 排除已转商机／淘汰；使用可见线索服务 |
| 漏斗总览 | 缺数字 | 累计转商机线索／全部可见线索百分比 | 展示明确的累计线索转化率；无样本不显示 0% |
| 阵地经营／客户管理 | 客户数 | 保留可见客户数；提示不可达关键人 | 复用范围化客户服务及判断来源 |
| 商机管理 | 开放商机数 | 保留；提示商机金额 | 复用范围化商机服务，不统计已结束商机 |
| 商机报价 | 待审产品行数 | 待审批报价商机去重数 | 同一商机多条待审产品只计一次；提示说明是报价商机 |
| 战果沉淀／项目交付 | 全部项目数 | active／on_hold 在交付项目数 | 避免已结束项目挤占执行数字，项目门控 |
| 回款管理 | 在交付合同总额，不能说明待回款 | 待回款笔数；提示逾期笔数 | 排除已结清／核销，复用回款和项目读取门控；两次集合读取，避免逐项目查询 |
| 续约管理 | 临近到期数 | 保留 | 排除已有续约商机项目；上游读取失败不假定尚未续约 |

## 跨域入口与兼容项

- 首页、销售大屏、赋能分析、战略诊断：聚合展示，不加一个含义模糊且与业务模块重复的数字。不是漏取业务计数。
- 旧销售区域、预测规则、线索分派兼容项：不再单独出现在 Launcher；保留既有路由数据时，分别按区域数、预测分歧数、未分派开放线索数命名。
- 失败隔离到单个来源，不把读取异常转换成空列表。其余板块继续显示已成功读取的结果。
- 重点客户明确使用自然年；C04 继续核实下一年度案例入口，不能默默把下一年人数写成今年数字。
