## 身份与承接

标题在名称后始终保留战略类型与价值主张两个位置；销售承接标记位于右侧人名之后、操作菜单之前。未设置时显示「未设类型／未设价值主张」，
有标识但缺少冻结词表名称时为「价值主张待核对」，不显示 UUID、不用当前词表覆盖发布历史。
两类标签的提示明确字段身份，状态／版本和销售承接状态独立表达。

销售承接通过规划域只读服务读取最小投影，复用规划、战略与来源权限及工作区范围校验。
只统计当前有效、已发布待生效、编辑者可查看的草稿和已结束规划，不把被替代的发布历史作为当前承接。
多个目标承接合并为一项规划／战略版本记录，不向卡片发送目标金额、负责人等额外内容。

| 提示 | 含义 |
| --- | --- |
| 销售规划已承接 | 本版本至少一个目标进入当前有效销售规划；不表示所有目标均已承接 |
| 销售规划待生效 | 本版本进入已发布但尚未生效的规划 |
| 承接待发布 | 本版本仅存在于有权查看的规划草稿 |
| 销售规划承接旧版 | 其他战略版本已被有效／待生效规划承接，本版本尚未承接 |
| 发布后可承接 | 未发布的战略草稿尚不能承接 |
| 销售承接已结束 | 同版本的承接所属规划已结束 |
| 销售规划待承接 | 当前可读取的工作版本无本版本承接 |
| 承接状态不可见／待查询 | 权限不足或读取失败，不误报未承接 |

悬停或键盘聚焦显示年份、销售规划版本、战略版本和规划状态。卡片不据此写入或修改承接。

## 信息布局

目标市场和产品方案使用同一自然布局：按原业务顺序尽可能展示完整条目，空间不足时保留至少一项，
长名称省略并可查看全名，其余汇入 `+数量`（不带括号）。目标市场主攻优先，不再固定只展示一项。
悬停列表一行一项并保留原模块链接；数量入口也可点击进入战略详情，键盘／触屏不依赖鼠标悬停。
宽度、字号和密度变化后重新计算，不额外复制客户规模信息。

实测承接 Tooltip 受到 `max-w-xs` 的产品编译结果影响，最大宽度仅8px；移除该通用类，
改用现有 DS overlay-xl 宽度上限与视口留白令牌。关联 HoverCard 同时核对实际宽度，
不让提示宽度受触发标签宽度限制；未新增 DS token。

资源缺失用 DS body-small、中性色、普通字重提示，真实数值保留 body 和单位，0 仍是有效数值。
沿用现有 DS Card、HoverCard、Tooltip、菜单及字号／间距／颜色 token，无新增 token。
