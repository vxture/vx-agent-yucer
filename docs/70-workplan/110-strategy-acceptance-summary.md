## 本批边界

用户确认销售规划只承接能够分解并验证兑现的标准战略目标。当前为营收、渠道建设、
标杆案例。自定义目标留在战略侧；新客、管道不在缺少完整战略链路时虚增支持。
指标汇总是确定性计算，不需要大模型猜测归类。

本批与修订说明必填修正（#723 / PR #724）分别审查，后续统一安排发布。
遵循用户要求，完成后停留本地预览，不自动打应用版本标签。

## 已实现

| 内容 | 行为 |
| --- | --- |
| 位置与层级 | 年度目标前的轻量承接卡片，默认收起并记忆偏好；收起保留战略数及标准指标合计 |
| 展开入口 | 卡片最右侧显示“展开／收起”及方向箭头，标题不兼作折叠按钮 |
| 多战略 | 来源战略顺序固定，桌面每战略两行；小屏响应布局，无拖动排序 |
| 汇总口径 | 合计承接值，同币种独立，金额按分精确计算；不与年度目标重复相加 |
| 区域口径 | 仅本区域分配，未分配与明确零值区分；公司承接保持只读 |
| 集中编辑 | “承接战略目标”抽屉集中勾选一个战略的多个指标，切换来源保留本次修改 |
| 对齐与安全区 | 承接人固定居右；DS md 512px 抽屉；固定操作栏、80px 底部安全区 |
| 抽屉密度修正 | 每指标两行：首行左侧整合指标名、承接数量与单位，右侧承接人无独立 label；次行说明默认一行并随内容增高、删除后回缩。规则说明收进来源帮助，战略预期保留在指标名提示中 |
| 选择列缩进 | 勾选框独占左侧选择列，两行内容共同缩进；说明左缘对齐数量框、右缘对齐承接人，避免第二行回到勾选框下方 |
| 整项取消 | 摘要中的 × 直接取消公司草稿承接；历史发布、保留项目的区域分配保持不变 |
| 关闭周期 | 界面禁止取消含关闭季度分配的项目；既有发布校验继续保护关闭周期 |
| 来源与权限 | 沿用标准指标标识、来源 UUID、已发布来源版本、权限及年度重叠限制 |

## 数据库变更

`deploy/database/ddl/incr/0132_company_strategy_cancellation.sql` 更新现有工作流触发器，
仅允许公司草稿整项取消承接；不能借此修改保留承接的区域分配或其他区域字段。
区域草稿仍受已发布公司基准约束。无表结构、列、Prisma 模型及权限目录变更。
