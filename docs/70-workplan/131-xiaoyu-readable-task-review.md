## 验收边界

- 内部关联键保留原值；页面正文、选项、提示、摘要及可见链接文字不得显示 UUID，也不得截短冒充名称。
- 名称与选项只取当前用户、当前工作空间授权范围；无权或失效关系不以历史标签补全。
- Markdown 不执行原始 HTML，不允许危险 URL；用户输入仍按普通文本显示。
- 查询结果不能只留在来源卡；明确对应客户的已核实事实要进入待复核原生字段。冲突、未知、仅模型猜测不能自动当事实。

- 多表单同步按任务串行，避免并发 revision 冲突；单项错误不得误报全部完成。
- 原复杂会话错误仍未真实闭环；PR #789 为失败阶段识别与来源批量提交修正，已合并，不宣称修复生产根因。
