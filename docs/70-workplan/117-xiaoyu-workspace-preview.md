## 二、本批能力边界

任务 API 沿用 01A 的新鲜服务端身份、空间与来源校验。本地使用真实 HTTP API 和服务逻辑，
但预览明确开启 dev-session 且没有数据库，任务及笔记只在该预览服务进程内保存；进程重启后不保留。
生产持久化实现与双库验证见 [116](116-xiaoyu-task-foundation.md)，不能把本地内存刷新恢复视为生产持久化实调。

当前交付连续任务和私有笔记。跨会话长期记忆、独立共享业务知识、今日判断议题、
受控业务字段读取、Atlas／Runos 调度、跨板块表单草稿与授权提交继续由 02A 至 04B 交付。
界面明确显示阶段提示，旧聊天不自动合并，新任务不临时开放业务读写工具。
原页面填写仍使用原表单助手状态，不宣称已与新任务上下文融合；04A 迁移后再消除此视图区别。
三种模式继续服务原有能力，不赋予新任务尚未接通的执行权限。

未发送输入和未保存笔记可随同一浏览器内的页面／侧栏切换保留；刷新前提示未保存内容。
已保存笔记通过服务恢复。切换到另一个任务前需先保存当前笔记；不把未发送文本默认为长期记忆。
当前页面提示独立于任务目标；关联动作只登记经服务器验证的 UUID，不读取业务字段或回填另一个表单。
