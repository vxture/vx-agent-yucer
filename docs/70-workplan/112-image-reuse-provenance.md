## 问题与范围

Issue #728。遵循既有健康端点身份与不可变镜像约定，不改变环境路由、审批或业务权限。

## 修复

两个仓库均无镜像时允许构建；只有一份时停止并要求恢复缺失副本。
读取两个仓库实际 Docker runtime Config.Env，核对版本、环境、8 位提交及 image ID；
任何不匹配、无法读取、重复身份键均停止，不通过重新打标签伪造发布身份。
仓库连接或认证异常也停止，不视为镜像不存在。相同版本与提交的重试仍可复用。
