# 战略修订说明保存校验

跟踪 [Issue #723](https://github.com/vxture/vx-agent-yucer/issues/723)。
状态：修正与本地验收完成，停留本地预览，待用户确认后随后续批次发布；生产仍为 v0.1.124。

## 问题与修正

- 旧流程只在发布时验证修订说明，编辑页未标必填且保存可通过，反馈滞后。
- 修订草稿的说明标注 DS 必填星号，声明无障碍必填与错误关联；离开字段或点击保存时就地提示。
- 保存前拒绝空值和纯空白，聚焦并滚动至字段，不发送无效保存请求；填写有效内容后清除提示。
- 领域保存同步检查有效说明，防止绕过页面；省略字段保留既有有效说明，显式清空则拒绝。
- 首版新建和首版草稿编辑不要求修订说明；发布时的兜底校验保留。中英文提示同步。
- 不改变版本、UUID、并发令牌、授权及数据库结构；助手的修订草稿同样经过领域保存校验。
