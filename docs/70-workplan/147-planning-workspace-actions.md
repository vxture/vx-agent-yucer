## 摘要与草稿

- 战略以「执行中 X 项战略｜待发布 X 项｜销售规划已承接 X/Y」表达，待发布数量使用warning令牌。
  点击待发布数字或页面操作菜单的同名入口，显示可继续办理的初始和修订草稿；普通总览仍每条战略只显示当前版本。
  清单提示当前为待发布筛选，可从菜单回到全部或使用清除筛选；进入执行跟踪时清除草稿筛选。
- 待发布仅计基础版本仍有效的草稿；旧基础版本已被替代、结束或归档的失效草稿不混入数量。
  摘要与筛选复用同一纯业务投影，搜索文字不改变摘要，周期仍生效。
- 细分市场使用「已启用」，以「全部配备了产品方案」替代0个待配，仅在确有启用市场时出现。
- 方案无缺项时显示「方案构成与标准价均已配齐」，不暗示可选项价格或完整客户报价均已验证。
- 全部可见产品确为在售时显示「全部为在售产品」；无在研但有退市或自定义状态时说明非在售数量。
  空集合不显示「全部」；数据未知仍为待核对，不回退为零或完成。
- 竖线、间距、正文／数字、关注色继续引用现有DS token，支持主题、密度和字号配置，不增加token。

## 两层操作对应

| 板块 | 页面标题右侧 | 清单标题行 |
| --- | --- | --- |
| 市场战略 | 保留新建及既有菜单，补待发布筛选／回全部 | 周期、搜索、视图切换直接保留；待发布模式显示提示 |
| 细分市场 | 外部新建；三竖点提供细分检查、获授权的市场战略入口 | 搜索、状态、视图和比较市场保留；比较后显示比较所选／取消，不藏进菜单 |
| 解决方案 | 外部新建；三竖点提供产品目录、有产品编辑权限时的系统配置 | 搜索、产品类型、视图保留；没有其他清单动作，不人为造空菜单 |
| 产品目录 | 外部新建；三竖点提供获授权的解决方案、系统配置 | 搜索、产品类型、视图保留；价格记录收入清单三竖点，选中后清除选择直接显示 |

系统配置均在当前标签定位既有`/admin/product`，不更改配置导航或新建／编辑页内部排序布局。
对象级查看、状态变更、排序、删除及原有确认仍在各卡片／行菜单内，不把对象动作提升为页面操作。
权限判断沿用服务端`can()`；隐藏没有权限的跳转，不把方案编辑权限当作产品配置权限。
