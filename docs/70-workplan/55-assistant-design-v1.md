## 页面与交互映射

| 规范项 | 聿策实现 |
|---|---|
| Header | DS ShellHeader，card 白底、border 下边线，无阴影 |
| 侧栏 | DS ShellDock，surface-3、无圆角外框，左缘 token 淡阴影 |
| 窄/宽 | DS 420px / clamp(480px,46vw,760px)；小屏覆盖，避免挤压正文 |
| 全屏 | 只覆盖 Header 以下工作区；Header 可用，对话阅读宽度最高 880px |
| 固定区域 | 框架标题、输入、底部模式；中间推荐与对话伸缩 |
| 页面适配 | 首页、配置管理不展示右栏；智能工作台拥有主对话，不重复显示第二个助手；本产品没有地图/我的场景 |
| 授权入口 | 底部左侧点击向上菜单，单选态、图标、名称和说明；Escape/外部点击关闭 |
| 无修改权限 | 可以展开阅读；不可修改的条目显示门禁原因，不再禁用整个入口 |
| 推荐 | 无数据隐藏；默认摘要、独立展开；输入自动收起，允许手动展开；矮视口自动折叠 |
| 对话 | 用户消息按内容靠右、图标在右；普通回复全宽，无头像、身份行或卡片 |
| 输入 | DS Textarea 自动增高；桌面 72–144px、手机 64–120px；Enter 发送、Shift+Enter 换行、IME 不提交 |
| 历史 | 接近底部才跟随；阅读历史时保留位置，并提供“有新消息”入口 |
| 失败 | 原请求保留，沿用服务端 recovery 重试，不重复显示用户消息 |
| 关闭重开 | 隐藏而非卸载，保留草稿、对话与请求；进行中关闭提示可重新打开查看 |
| 客户登记 | 顶部与右侧共享同一草稿，框架标题不被任务名替代 |
| 通用右栏 | 复用 askCopilot → runCopilotTurn → Atlas/Runos；不再只能跳转“问参谋”；保留明确的人工“记为跟进”操作 |

极矮视口优先保证输入和发送，允许缩短对话最小高度。

## 三档文案与服务端语义

| 名称 | 小字说明 | 数据标识 | 图标 |
|---|---|---|---|
| 逐项确认（默认） | 每项操作前请你确认。 | ask_always | list-checks |
| 常规授权 | 常规自动，重要或存疑时确认。 | ask_high_risk | target |
| 充分授权 | 授权范围内自动执行。 | autonomous | 同源 Phosphor Robot，DS 当前无 robot 别名 |

菜单常驻提示：**删除、覆盖等高危操作仍需确认。**

保留工作区 agent_autonomy、签名人与服务端权益/角色门禁；不擅自改成个人设置，
不把前端模式当成实际授权。模式切换继续经过 setAutonomy。

- 风险由 ACTION_RISK 注册，模型不能临时将写入降为常规。查询、分析和未提交草稿沿用只读工具。
- 当前业务提案处理器均正式写记录，登记为 important；客户字段/角色变更可能覆盖原内容，登记为 destructive。
- 常规授权下重要提案须确认；充分授权可通过已登记重要提案的自动执行判定；destructive 和未知类型在全部模式下等待确认。
- 执行仍经过 execute 和各业务域服务，重新检查权限与当前提案状态。
- 覆盖类提案在队列和商机侧栏采纳时使用 DS ConfirmDestructive；普通批量裁决使用 DS DialogForm。失败保留确认界面。
- 不新增删除、对外发送、发布、批量写入等处理器，不把未接通动作显示为已完成。

## 服务端后续项与验证边界

保留现有提案不可变 payload、workspace/subject 归属、状态机、授权签名与审计。
规范要求的独立任务授权凭据（对象/动作/成本/有效期与撤销）、跨实例执行幂等、
确认到执行之间的对象版本校验，以及可取消后台任务，需要服务端后续补齐，跟踪 [#652](https://github.com/vxture/vx-agent-yucer/issues/652)。
不能以工作区模式或本轮布局完成代替这些能力；本轮不增加无人值守自动批处理入口。

浏览器使用受控测试响应检查状态与回填，不等于真实生产模型验收。
本地没有 Atlas 模型连接；生产客户真实多轮回填继续由 Runos #130 跟踪。
