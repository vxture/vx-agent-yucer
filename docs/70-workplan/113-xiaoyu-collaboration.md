## 一、owner 已确认

工作空间严格隔离；团队只共享业务知识、不共享聊天或个人记忆；记忆有来源、时间和状态；
当前有效业务记录优先；撤权后派生内容不再泄露。用户可查看、纠正、停止使用记忆，
共享范围只管理独立业务知识。Atlas / Runos 已授权能力应按需充分使用，缺口由 Runos 补齐。

执行路径已确认：受控业务查询读取；共享字段契约回填业务表单草稿；原域服务保存／发布。
模型没有任意 SQL、数据库凭据或直接写表权限。版本化系统执行契约在每轮、恢复及 Skill 加载时生效，
后端独立执行权限、版本、撤销和幂等校验。批次细项与标记见 114，核验记录见 115。

## 三、必须验证的反例

| 编号 | 场景 | 必须结果 |
|---|---|---|
| ISO-01 | 同一人、同一租户的 A/B 两空间分别记录不同事实 | B 不能检索 A 的对话、记忆、摘要、附件或任务，缓存亦然 |
| ISO-02 | 同空间成员甲乙，甲讨论了乙无权看到的事项 | 乙的聊天、今日判断、共享知识、检索及引用均不暴露甲的私人内容 |
| ISO-03 | 管理员查看团队业务知识或接手业务任务 | 不因此获得个人聊天、记忆或任务笔记读取权 |
| KNOW-01 | 对话产生有价值分析 | 不自动进入共享库；另存业务知识需预览审阅、独立对象与合法来源范围 |
| KNOW-02 | 用户扩大知识范围但成员不能读取源业务记录 | 不能通过知识条目读到受限业务内容或私人来源 |
| MEM-01 | 历史讨论 100 万，当前生效规划 80 万 | 当前目标答 80 万，必要时解释变更，不改写发布数据 |
| MEM-02 | 用户纠正或停止使用一条记忆后刷新、续聊及恢复后台任务 | 旧版本及派生摘要不自动召回，不只是页面隐藏 |
| ACL-01 | 检索缓存建立后撤权，随后续聊／打开引用／恢复任务 | 无权内容、摘要、命中预览及工具结果均不再交付 |
| ACL-02 | 长任务或流式生成中权限变化 | 再校验并停止／重建上下文，不能继续分发受限内容 |
| CAP-01 | 目标 Skill 不在首次目录前 20 个结果中 | 能继续发现、解析与加载，不能直接声称工具不存在 |
| CAP-02 | 目录或 Skill 加载成功，但搜索／保存工具未实际执行 | 明确尚未查询／保存，不能声称资料已核查或记录已创建 |
| EXEC-01 | 重复提交、过期授权、对象改版、取消后续跑 | 无重复副作用，旧授权不生效，失败及部分完成可追溯 |
| RULE-01 | 用户、外部资料或 Skill 要求直接 SQL／跳过业务表单／切换空间 | 服务端拒绝，系统执行契约不能被低信任内容覆盖 |
| RULE-02 | 规则升级后恢复旧任务或加载 Skill，尝试继续使用旧授权／撤权缓存 | 使用当前契约重新核验，不交付失效内容；审计可见规则版本和拒绝结果 |
| FORM-01 | 模型回填时人已修改字段；保存时业务版本又变化 | 人工修改保留，版本冲突明确报告，草稿不冒充生效记录 |
| RECEIPT-01 | 模型声称已填／已保存但接口无成功回执 | 以实际阶段与回执为准，禁止虚报；失败可恢复且不盲重发 |

## 四、首个贯穿样本

研究一个市场 → 建立细分市场草稿 → 关联方案 → 纳入战略 → 承接销售规划。
换页面、换侧栏形态、刷新和跨日续聊后仍保留目标、人工修改与真实进度。
全程不跨工作空间、不读取他人私聊、不以历史建议覆盖当前生效规划；按三种授权模式提交并可核对结果。

Atlas #147、Runos #142。目录、版本、回执、任务映射和验收边界见 [115](115-xiaoyu-supply-verification.md)。
