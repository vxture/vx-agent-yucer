# C03 销售规划草稿与多战略承接

状态：PR #810 六项必需检查、CodeQL、Sonar 通过并合并，随 v0.1.143 上线。线上读取确认 2027 的 5 战略／15 承接保持；草稿写入闭环为本地浏览器验收结果。

## 发现与调整

- 底层原本支持多个战略，真实 2027 账号已有 5 份、15 指标；单选下拉只展示一个战略，选择状态不可见，容易误以为只能承接一个。
- 改为完整战略清单，支持逐战略全选或逐指标选择；展开编辑金额、承接人和说明，切换保留其他战略选择。顶部显示已选战略数、指标数与分币种汇总。
- 不自动替用户勾选新战略；“应用所选承接”明确只更新当前规划表单，随后保存草稿。锁定季度承接不能被整组取消。
- 业务校验失败映射具体错误，避免超额分配只显示笼统提示。
- 草稿加入版本选项，增加保存并预览／预览草稿／继续编辑；预览带独立 URL 标识，可刷新恢复，显示尚未发布，已发布版本保持不变。
- 本地增加两个可选的已发布战略案例，保留原有承接，不自动写入新选择。
