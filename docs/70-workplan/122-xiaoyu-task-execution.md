## 实现边界

DDL 0138 新增执行步骤、任务授权、执行回执三个对象，共 135 张表与 Prisma 对齐。
提案事实及回执不可改；步骤仅允许记录尝试时间／失败码，授权仅允许单向撤销。
引用关系全部使用 UUID；复合外键中的 actor_sub 是平台主体隔离条件，不是业务编号。

首批保存覆盖细分市场、解决方案、战略和销售规划；发布覆盖战略和销售规划。
发布只处理已保存且与表单内容一致的草稿，不在发布时暗中保存修改。
公司规划保留原版本、校验、发布和战略承接服务，不另造自动写表路径。

旧提案的人工确认入口保留；其副作用与 executed 状态同事务提交，重复提交恢复既有状态，
并按实际执行时钟检查有效期。旧入口不再仅凭工作空间模式自动执行；未迁入任务范围凭据的
客户／商机七类旧动作仍需人工确认。此限制如实列入迁移矩阵，不宣称全部业务已支持无人执行。

后台恢复以持久化步骤和回执为准。授权请求可依次执行具体步骤；浏览器响应丢失后重新核对。
没有无限重试或隐含的跨域全事务；多步骤中已完成的动作不因后续失败而伪装回滚。
