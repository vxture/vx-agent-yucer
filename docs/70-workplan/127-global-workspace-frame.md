# 127 - 全局页面框架与逐页验收清单

本批依据 owner 2026-11-24 确认：先统一所有业务页面的通用框架。
来源为 scripts/guardrails/page-surfaces.json 与实际 App Router 文件反向核对。
共 85 个独立页面、76 个配套 AI 并行槽位；并行槽位不重复计算为页面。

## 固定规则

- 普通业务页使用可组合的外层框架，左右按需出现，不要求每页三栏。
  业务左栏为对象档案，采用 DS ShellSidebarFrame expanded（默认密度 256px）；
  右栏承载小聿，保留 DS ShellDock 窄／宽档。依据 owner 补充，左右不再强求同宽。
- 配置导航独立保留原有 ShellViewport sidebar 插槽与 DS 展开／图标折叠行为，
  不改为信息面板、不增加面板显隐开关、不修改导航自身留白和内部布局。
- 左右栏进出与中部伸缩统一采用 DS slow／standard（默认 300ms）过渡，参考配置导航。
  关闭后保留挂载，结束后隐藏，不让未保存内容重建；减少动态效果时取消过渡。
- 中部标准／宽屏上限为 1536／1920px，包含左右留白；最大净内容为 1440／1824px。
  侧栏不计入中部上限，中部根据剩余空间弹性收缩。
- 桌面左右留白默认 48px；窄容器弹性缩小。Header 下滚动避让保持 HTML 的 12px。
- 使用真实 DS token 和 ShellPageContainer／ShellDock，不复制 DS 组件、不新增 AI 专属尺寸。
- 底部为 space-6xl（默认 80px）与设备安全区；固定输入／操作区单独避让，避免重复堆叠。
- 头像 → 偏好设置 → 显示与布局 → 内容宽度。按账号＋产品隔离，本期浏览器持久化，
  不宣称跨设备服务端同步。刷新首屏读取同一偏好；切换不重建表单、任务和未发送内容。
- 大屏保留独立全屏形态；登录／门禁保留 CoSpace 规范。兼容地址继续跳转。
- 业务集合页保留原有聚合布局，只共享适用的外层宽度、留白与滚动规则。
  Drawer、Dialog、Popover 及侧栏内部保留各自 DS 布局和宽度档位，不嵌套三栏。

## 验证记录

2026-11-24，本地隔离工作树，单一 4060 开发服务，内存演示数据。
未连接业务数据库，未调用模型、保存业务表单或发送对话；不代表真实授权或生产验收。

- 页面盘点：85 个独立页面、76 个 AI 并行槽位，机器检查零错误；逐页浏览器记录按两段合并，85/85。

- 最终版本在 390、1024、1440、1920px 的战略、客户详情、商机详情、配置、协作页共 20 组检查通过；
  2560px 两档中部封顶、个人设置及刷新恢复通过。大屏及非业务预览沿用自身结构。
