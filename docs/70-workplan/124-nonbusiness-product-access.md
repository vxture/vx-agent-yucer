## 接入配置清单

| 参数 | 聿策事实 |
|---|---|
| 产品 / origin / OIDC client | yucer / https://yucer.vxture.com / yucer |
| 模式 | 产品业务授权；不增加独立身份试点或 beta |
| 会话 | `/auth/session` GET 只读，POST 同源确认；服务端每请求核验 |
| CSRF | Origin 必须匹配可信 `NEXT_PUBLIC_APP_URL`；不新增客户端票据 |
| 登录 / callback | `/auth/login`，`/api/auth/oidc/callback`；复用 safeReturnTo |
| 身份 / 范围 | 服务器验证 sub、active_org、active_workspace；姓名与组织全称来自令牌 |
| 商业事实 | C2 原有 tier / bundled 两公式保持不变，不在产品计席位 |
| 成员产品分配 | `GET /platform/product-roster` assigned_seats，组织绑定服务票据 |
| 产品角色 | 名单通过后才可初始化 sales_rep；保留明确降权、撤角、停用 |
| 撤权 | 每个服务端请求重读名单；名单无缓存，分页冲突全量重读；owner 无席位豁免 |
| 运行中确认 | 可见时每 15 秒，返回标签和主动重试重新确认；合并在途检查、25 秒超时 |
| 故障 | 权威读取失败显示暂时无法确认权限；不能沿用旧名单或当作未开通 |
| 工作恢复 | 临时未知时原树隐藏并 inert、阻断业务 fetch，丢弃跨失效响应；同范围恢复保留内存工作；授权或身份改变硬刷新清除旧树；不重放写入，不承诺持久草稿 |
| 平台账号中心 | https://accounts.vxture.com/account，与产品现有用户菜单一致 |
| 购买 / 续订 | C2 不提供权威购买管理资格，不从产品管理员或 workspace manager 推断；当前隐藏跳转，只提供重查和管理员说明 |
| 外链 | 仅代码或可信配置定义 HTTPS origin；不接受页面查询参数作为外部目标 |
| 视觉 | 408px 单卡片、40px 内边距、24px 标题、48px 操作、24px 身份图标、固定装饰中心；小屏自然增高滚动 |
| 预览 | `/gate-screens` 仅静态样例，不伪造生产会话、名单或状态查询参数 |
| 数据库 / 配置 | 无新增结构、凭据或部署配置 |
