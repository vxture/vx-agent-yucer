## 原因与调整

标签原使用 body-small，内容使用 body；行使用 baseline 对齐，字号和嵌套盒子让首行位置不一致。
两个关联类型原本都取前两项，但 flex-wrap 让不同长度名称自由换行，并非业务规则不同。
左右列使用 subgrid 共用三／四条网格行，某侧换行会同步拉高另一侧，产生无内容的空行。

本批使用已有正文、间距、图标 token，不新增 DS token、不改全局控件规则、不改业务读取和写入。
左右改为独立纵向排列；目标多于四项的入口留在目标列。自定义指标直接展示其业务名称。

同时纳入上一轮 owner 的按钮偏好文档记录：主要按钮14px、次要12px，同行尽量同尺寸并允许合理例外；
该记录未带来本批按钮或全站 CSS 改动。
